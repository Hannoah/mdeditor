# 📝 mdeditor

Rust로 만든 **초경량 Markdown 편집기 & 미리보기 웹 서비스**입니다.
외부 크레이트 **의존성이 전혀 없이(zero-dependency)** 표준 라이브러리만으로 구현되어 매우 가볍고 빠릅니다.

## ✨ 특징

- **의존성 0개** — `std`만 사용 (빌드 빠르고 바이너리 작음)
- **실시간 미리보기** — 편집하면 오른쪽에 즉시 HTML 렌더링
- **파일 관리** — 작업 폴더의 `.md` 파일 목록 조회 / 열기 / 저장
- **다크 테마 UI** — 2분할(편집 / 미리보기) 레이아웃, 실시간 문서 통계(글자 수/줄 수), 에디터-미리보기 스크롤 동기화
- **단축키 & 편집 편의** — `Ctrl + S` 저장, `Tab` 들여쓰기, `Shift + Tab` 내어쓰기
- **안전한 저장** — 임시 파일에 쓴 뒤 교체(저장 중 크래시해도 원본 보존), 저장 안 한 변경이 있으면 경고, 읽기 실패(UTF-8 아님 등)는 빈 문서로 위장하지 않고 오류 표시
- **보안** — 작업 폴더 밖 접근 및 상위 디렉토리 이동(`..`) 차단, `.md`/`.markdown` 파일만 허용,
  `Host`/`Origin` 검증(DNS rebinding·CSRF 방어), 요청 본문 10MB 상한·타임아웃·동시 연결 제한,
  `javascript:` 등 위험한 링크 스킴 차단

## 📦 지원하는 Markdown 문법

| 문법 | 예시 |
|------|------|
| 제목 | `# H1` ~ `###### H6` |
| 굵게 / 기울임 | `**굵게**`, `*기울임*`, `***둘 다***` |
| 취소선 | `~~취소선~~` |
| 인라인 코드 | `` `code` `` |
| 코드 블록 | ` ```...``` ` |
| 링크 / 이미지 | `[텍스트](URL)`, `![대체텍스트](https://...)` (http/https/mailto/#만 허용) |
| 목록 | `- 항목`, `1. 항목` (들여쓰기로 중첩) |
| 체크박스 (태스크) | `- [ ] 할 일`, `- [x] 완료된 일` |
| 인용 | `> 인용문` (여러 줄·중첩·목록 포함) |
| 표 | `\| a \| b \|` + `\| --- \| :---: \|` (정렬 지원) |
| 구분선 | `---`, `***`, `___` |
| 이스케이프 | `\*`, `\[` 등 |

- 연속된 줄은 한 단락으로 합쳐지고, 줄 끝에 공백 2개를 두면 줄바꿈입니다.
- 짝이 맞지 않는 `*`, `` ` `` 는 문자 그대로 표시됩니다.
- 미지원: `_밑줄_` 강조, 참조 링크

## 🚀 빌드 & 실행

```bash
# 프로젝트 폴더에서
cargo run --release
```

실행 후 브라우저에서 접속:

```
http://127.0.0.1:8080
```

> 서버는 **실행된 현재 디렉토리**(또는 인자로 넘긴 파일이 있는 폴더) 안의 `.md` 파일을 읽고 저장합니다.
> 원하는 문서 폴더에서 실행하거나, `mdeditor 경로\memo.md` 처럼 파일을 인자로 넘기세요.
>
> 8080 포트가 이미 쓰이고 있으면 8081~8089 를 순서대로 시도합니다.
> 같은 폴더를 서비스하는 mdeditor 가 이미 떠 있으면 새로 띄우지 않고 브라우저만 엽니다.
> 다른 폴더의 파일을 열면 별도 서버가 다음 포트에서 시작됩니다.
>
> `MDEDITOR_NO_BROWSER=1` 이면 브라우저를 열지 않습니다.
> 브라우저 자동 열기는 Windows(`start`) / macOS(`open`) / Linux(`xdg-open`)를 지원합니다.
> `mdeditor.bat` 는 Windows 용 런처이며, 릴리즈 바이너리가 없으면 먼저 빌드합니다.

## 🗂️ 프로젝트 구조

```
mdeditor/
├── Cargo.toml          # 패키지 설정 (의존성 없음, 릴리즈 최적화)
├── .gitignore
├── mdeditor.bat        # Windows 런처 (더블클릭 / 파일 끌어다 놓기)
├── README.md
└── src/
    ├── main.rs         # HTTP 서버 + API 라우팅 + 경로 보안
    ├── markdown.rs     # 경량 Markdown → HTML 파서
    └── index.html      # 편집기 UI (순수 HTML/CSS/JS, CDN 없음)
```

## 🔌 API 엔드포인트

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/` | 편집기 페이지 |
| GET | `/api/info` | 서버 식별(앱 이름·작업 폴더) — 중복 실행 판별용 |
| GET | `/api/list` | 작업 폴더의 `.md` 파일 목록 (JSON) |
| GET | `/api/load?file=이름.md` | 파일 내용 불러오기 |
| POST | `/api/render` | 본문(Markdown) → HTML 변환 |
| POST | `/api/save?file=이름.md` | 파일 저장 |
